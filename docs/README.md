# PriceLens — Documentation Index

PriceLens is a self-hosted, multi-site product search and price comparison tool for a small team on a local network.
This `docs/` folder is the **single source of truth**. Every feature, fix, and refactor must be consistent with it; if code and spec disagree, update one of them deliberately in the same change.
