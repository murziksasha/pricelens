# PriceLens

Sign in with the account an admin created. The server address can stay empty when you open the UI from the server itself. On the Windows app, enter `http://<lan-ip>:3000`.

Search: tick sites (or a group), set price, condition and city, then search. Failed sites are listed and do not block the others. Visited rows are dimmed. Shortcuts: V visit, I interesting, R reject, B bought, Enter opens the listing, `/` focuses search.

Templates save a query and can run on a schedule. Purchases record a price and later a sale. Admins manage users, sites, the constructor, health, settings and backups.

The header switches English, Russian and Ukrainian, and light, dark or system theme. The choice is stored on your user.

Colleagues can see and export your searches, visits, marks and purchases; private notes stay yours.
